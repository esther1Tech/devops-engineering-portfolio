# Engineering Lifecycle & Software Delivery Process

**Course:** DevOps Engineering  
**Assignment:** 01  
**Topic:** Engineering Lifecycle & Process

## Overview

This assignment explains how application code and machine learning models move from development to production. It covers Git branching strategies, the DevOps lifecycle, the MLOps lifecycle, and code promotion through different environments.

## 1. Git Branching Strategy

Explain how developers use branches to work on new features without affecting the main codebase.

Cover:
- Main branch
- Develop branch (if used by the team)
- Feature branches
- Pull requests and code reviews
- Branch protection rules

## 2. DevOps Lifecycle

Explain the following stages:

Plan → Code → Build → Test → Release → Deploy → Operate → Monitor

Describe what happens at each stage and which tools can be used.

## 3. MLOps Lifecycle

Explain how machine learning models move through:

Problem Definition → Data Collection → Data Preparation → Model Training → Model Evaluation → Model Registry → Deployment → Monitoring

Describe how MLOps differs from traditional DevOps.

## 4. Code Promotion and Testing

Explain how application code moves through:

Development → QA/Testing → Staging → Production

Discuss unit testing, integration testing, security testing, regression testing, performance testing, and smoke testing.

Explain why testing and approval are important before production deployment.

## Conclusion

Summarize how branching strategies, DevOps, MLOps, CI/CD, and testing help teams deliver reliable applications and machine learning models.
